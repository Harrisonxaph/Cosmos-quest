# Roadmap

1. Foundation: schema-validated facts, citations, licence inventory, mirrored tests, CI and Pages workflow.
2. Exploration: add a 3D scene with selectable planets, labelled illustrative scale, keyboard/touch controls, pause and reduced-motion behavior. Agree the rendering library before implementation.
3. Learning: add age-appropriate fact panels and a simple quiz with feature tests, using only cited content.
4. Release review: verify facts against primary sources, inspect every asset licence, and test on mobile devices and with keyboard navigation.
